# Native screenshots

Generated by `pnpm run native:screens` from the Expo playground on a booted
iOS simulator (darwin-only). Committed on purpose: these PNGs are both the
docs asset for `/native/<slug>` and the visual baseline for the React Native
catalog, so a component change shows up as an image diff in review.

They are absent until someone with a simulator runs the capture; the native
docs pages render a broken-image box until then, which is the honest state.
